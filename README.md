# DXを加速するローコード開発　サンプルコード

書籍『DXを加速するローコード開発 ── 「標準」を飛び出し、現場の「理想」をカタチにする』（楊　智瑛 著）の、サンプルコードです。

> 書籍の文章・図版は、このリポジトリに含まれません。コードの背景や、手順の説明は、書籍をご覧ください。
> 書籍の販売ページ：（公開後にURLを記載）

## 収録内容

| フォルダ | 内容 |
|---|---|
| [`book-code/`](book-code) | 書籍の本文に掲載しているコード（コード4-1〜コード6-5ほか） |
| [`exercises/`](exercises) | 演習の出発点になるコード |
| [`answers/`](answers) | 演習の解答例（PC向け／モバイル向け／両対応） |

## 解答例のファイル名の規則

| ファイル名 | 対象 | アップロード先（「JavaScript / CSSでカスタマイズ」画面） |
|---|---|---|
| `answer-X-Y.js` | PC向け | 「PC用のJavaScript / CSSファイル」の欄 |
| `answer-X-Y_mobile.js` | モバイル向け | 「スマートフォン用のJavaScript / CSSファイル」の欄 |
| `answer-X-Y_both.js` | PC・モバイル両対応 | 両方の欄に、同じファイルを追加 |

書籍の「解答例X-Y」が、`answer-X-Y` に対応します（例：解答例6-2 → `answers/chapter6/answer-6-2.js`）。
モバイル向けと両対応のファイルは、PC向けから、次の規則で作っています。

- イベント名：`app.record.…` → `mobile.app.record.…`
- API：`kintone.app.…` → `kintone.mobile.app.…`
- 両対応：イベント名を両方に登録し、APIは、イベント名（`event.type`）が `mobile.` で始まるかで切り替える（書籍の6.7節と同じ方法）

> `kintone.isMobilePage()` は、Promiseを返す非同期のAPIです。`kintone.isMobilePage() ? … : …` のように同期で使うと、常に「モバイル」と判定されます。このリポジトリでは、同期で判定できる `event.type` を使っています。

`book-code/` のコードは、書籍に掲載したとおり、PC向けです。

## 使い方

1. このリポジトリを、ZIPでダウンロードします（`Code` → `Download ZIP`、または、`Releases` のZIP）。
2. kintoneのアプリの設定 →「JavaScript / CSSでカスタマイズ」で、ファイルを追加します（「アップロードして追加」）。
3. 「保存」し、「アプリを更新」します。

文字コードは、UTF-8（BOMなし）です。まずは、練習用の環境で試し、確認してから、業務で使ってください。

### コード6-5について（kintoneの生成AI用API）

`kintone.ai.generateText()` は、開発を検討中のAPI（kintone APIラボ）です。使うには、次の2つの設定が必要です。

1. 「アップデートオプション」の「検討中の新機能」で、「kintone AI：生成AIでテキストを生成するJavaScript API」を有効にする
2. kintone AIを有効にし、AI機能の一覧で、「生成AIでテキストを生成するJavaScript API」を有効にする

APIキーは不要です。実行すると、AIクレジットを消費します。仕様は、正式版で変わる可能性があります。
